# ชุดข้อความสังเคราะห์จากข่าวสำหรับตรวจจับกลโกงภาษาไทย

ชุดเริ่มต้น 36 ข้อความ: `spam` 24 และ `ham` 12 ครอบคลุมพัสดุ/คืนเงิน งานภารกิจ เงินกู้ แอปปลอม ลงทุน และธนาคารปลอม สร้างโดย Codex จากรูปแบบที่ข่าวและคำเตือนอธิบาย ไม่ใช่ข้อความจริงจากผู้เสียหาย ไม่ได้เรียก Gemini หรือโมเดลภายนอกเพิ่ม

## ไฟล์

- `news_synthetic_dataset.csv`: UTF-8 BOM เปิดใน Excel ได้ มี `label,thai_text` ตามชื่อคอลัมน์ระบบเดิม พร้อมข้อมูลอ้างอิง
- `news_synthetic_dataset.jsonl`: ตัวอย่างเดียวกันสำหรับประมวลผล
- `sources.json`: ข่าว/คำเตือนและสรุปรูปแบบ แยกข่าวออกจากคำแนะนำทางการ วันที่ที่ไม่ได้ตรวจสอบใช้ null
- `generation_prompt.md`: พรอมป์ต์สำหรับสร้างตัวอย่างเพิ่มโดยให้ AI อิงแหล่งข้อมูล
- `build_dataset.py`: ส่งออกตัวอย่างที่เขียนไว้ใหม่ด้วย Python มาตรฐาน ไม่เรียก API

## ความหมายและข้อจำกัด

`spam` ในชุดนี้หมายถึงข้อความที่จำลองกลโกง ไม่ใช่โฆษณาทั่วไป ส่วน `ham` คือข้อความปกติ/คำเตือนที่มีคำคล้ายกลโกง แหล่งข่าวของ ham เป็นแหล่งของรูปแบบที่ใช้เปรียบเทียบ ไม่ได้หมายความว่าข่าวมีข้อความ ham นี้อยู่จริง ดู `derivation` ประกอบ

ทุกตัวอย่างเป็น `is_synthetic=true` และ `review_status=needs_human_review` ใช้เป็นชุดตั้งต้นเพื่อให้คนตรวจ ไม่ใช่หลักฐานความแม่นยำของระบบ ไม่ได้รวมใน master dataset หรือส่งเข้าฐานข้อมูล

ชื่อองค์กรเป็นสมมติและลิงก์ใช้ `.invalid` ไม่มีข้อมูลส่วนตัวจริง ควรทำรูปแบบลิงก์/placeholder ให้สมดุลทั้งสองคลาสก่อนฝึกโมเดล มิฉะนั้นโมเดลอาจจำคำว่า `.invalid` แทนพฤติกรรมกลโกง

ข้อมูลขนาดเล็กและแต่ละกลุ่มมีความคล้ายกันมาก อย่าสุ่มแยกข้อความในกลุ่มเดียวกันไปอยู่ทั้ง train และ test ให้แยกตาม `group_id`/ข่าวต้นทางเมื่อเพิ่มข้อมูล และใช้ข้อความจริงที่มีสิทธิใช้งานและตรวจโดยคนเป็นชุดประเมินแยกต่างหาก การแยกกลุ่มในชุดนี้เพียงอย่างเดียวก็ยังไม่ได้พิสูจน์ประสิทธิภาพ
